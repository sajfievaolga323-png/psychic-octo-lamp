# Аквариум — видеозвонки по ссылке

Что умеет первая версия:
- комната создаётся одной кнопкой, вход по ссылке (без паролей), гость вводит имя;
- видео и голос, демонстрация экрана, чат;
- живой аквариум за вашей спиной (или размытие, или без фона);
- текст из чата озвучивается голосом у всех участников: режим «сразу» или кнопкой «Сказать», плюс быстрые фразы.

## Переменные окружения (Vercel → Settings → Environment Variables)
- NEXT_PUBLIC_LIVEKIT_URL — адрес проекта LiveKit Cloud, начинается с wss://
- LIVEKIT_API_KEY и LIVEKIT_API_SECRET — из LiveKit Cloud → Settings → Keys

## Запуск у себя
1. Скопируйте .env.example в .env.local и заполните три значения.
2. npm install
3. npm run dev, откройте http://localhost:3000

## Выкладка
Загрузите файлы в GitHub-репозиторий call-khalin (без папок node_modules и .next) и дождитесь деплоя на Vercel.
Не забудьте добавить три переменные окружения и сделать Redeploy.

Звонить лучше в Chrome или Edge. Для камеры нужен https (на Vercel он есть).
